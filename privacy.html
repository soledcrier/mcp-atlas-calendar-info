Privacy / Google Calendar integration

隐私政策

适用程序：mcp-atlas · 版本日期：2026-11-11

mcp-atlas 是由 GitHub 用户 soledcrier 管理的独立研究接入程序，项目联系邮箱为 mirarchibowery@gmail.com。本文描述当前本地 Docker 接入如何处理通过 Google Calendar 获得的数据。网站只提供项目说明；Calendar 访问由另外运行的 MCP 工具和执行程序完成。

用途范围：Google Calendar 内容及包含这些内容的执行轨迹仅用于账号持有人授权的任务运行、reset 验证与审计，不用于模型训练。

1. 访问哪些 Google 数据

在账号持有人授予的权限范围内，程序可能读取日历 ID、名称、时区和访问角色，以及事件 ID、标题、描述、时间、时区、地点、组织者和参与者信息、状态、重复规则及其他 API 返回的事件字段。实际数据取决于题目、工具参数及 Google 的响应；完整事件内容可能被写入工具返回和轨迹。

权限当前状态与用途
calendar.readonly任务运行使用的独立只读授权；用于列出日历和读取任务所需事件。
calendar.events.owned仅供宿主维护使用的独立写授权；用于专用测试日历的工程事件恢复。该 Google 权限覆盖账号拥有的日历，单日历限制由维护配置执行。

reset 维护程序要求显式的专用日历 ID，并拒绝把 primary 作为恢复目标。该限制不等于 Google OAuth 本身仅授权一个日历。

2. 为什么处理这些数据

当前实现使用 Calendar 内容完成被明确配置的日程查询任务，并保存过程以便操作者检查模型行为和工具结果。宿主维护功能用于专用测试日历的工程事件初始化、恢复校验和重跑验证。当前工程验证覆盖标题、地点修改与有归属的新增事件清理；它不表示已验证任意 Calendar 写任务或完整官方基线。

3. 数据发送到哪里

执行程序通过 Google Calendar API 获取数据。后续模型轮次会把工具返回纳入上下文，经 LiteLLM 转发给操作者配置的模型服务或代理服务。因此，事件正文、参与者信息等内容可能发送给该服务，并不是只在 MCP 进程中读取。

数据接收方包括 Google（提供 Calendar API）、管理运行环境的项目操作者，以及操作者为该次任务选定的模型或代理服务。模型服务仅用于任务推理；操作者须向账号持有人说明实际服务商及其保存方式，并只连接处理约定符合本用途范围的服务。Calendar 数据不授权模型服务商用于训练；若这些约定无法确认，应停止向该服务发送 Calendar 内容。网站本身不接收 Calendar 内容。

4. 保存什么、保存多久

执行结果存储在操作者管理的运行环境中，包括模型请求与响应、工具原始返回、执行日志、结果及工作区产物。维护恢复使用的快照也可能保存完整事件内容。

当前版本没有为轨迹、导出和维护快照设置自动删除期限，文件保留至操作者清理。模型服务的输入副本和备份依据实际服务的处理约定管理，运行前由操作者确认。Google 原始日历、运行环境及模型服务持有的副本分别管理；删除一种副本不会自动删除其他副本。

5. 凭据与访问控制

访问 Google 的 OAuth Client Secret、Refresh Token 等凭据保存在服务器的私有环境文件中。维护凭据与任务运行凭据分开管理。源码包、镜像及公开说明页面不应包含密钥；主链路导出不包含任务环境文件。访问 Google API 使用 HTTPS。运行文件的访问由操作者控制，事件原始内容会保留在相关轨迹中。

轨迹可能包含原始数据。操作者应限制能读取轨迹、快照和备份的人员；需要人工检查具体数据时，应取得适用的用户同意或具有政策允许的其他依据。

6. Google 数据的使用限制

本应用使用及向其他应用转移从 Google API 收到的信息时，将遵守 Google API Services User Data Policy 及适用的 Google Workspace 用户数据及开发者政策，包括 Limited Use 要求。

Calendar 内容及其聚合、匿名化或派生轨迹仅用于任务运行、reset 验证与审计，不用于模型蒸馏、训练或改进通用 AI/ML 模型。匿名化或导出不会改变其用途范围。

本接入程序不包含出售日历数据、广告投放或信用评估功能。操作者须核实第三方模型服务的处理约定与本政策一致。

7. 撤销授权与删除

账号持有人可在 Google 账号的第三方连接管理中撤销访问权限。撤销后程序不能继续使用该授权取得新的 Calendar 数据；已保存的本地轨迹、快照、备份及模型服务副本不会随之自动删除。

需要清理已保存数据时，请联系项目操作者并说明运行或资源范围。不要通过邮件或网页发送 Token、Client Secret 或其他凭据。当前没有公开的自动删除接口；删除范围、备份及第三方副本的处理方式由操作者核实后回复。

8. 网站访问与后续修改

这份静态网站不设置应用 Cookie，不包含分析脚本、外部字体、表单或 Calendar 登录功能。GitHub Pages 可能为安全目的记录网站访问者的 IP 地址和访问日志，详见 GitHub 隐私声明。托管网站不接收 Calendar 内容、OAuth 凭据或任务轨迹。

当用途、接收方、保存安排或权限发生实质变化时，应先更新本文并取得所需的同意，再进行新的处理。联系地址同上。
