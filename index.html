01 / What it does

Calendar 在这里做什么

经账号持有人授权后，程序读取日历列表及任务所需的事件，帮助模型执行日程查询任务。运行记录用于检查实际工具调用及结果。

当前配置

任务查询使用只读凭据。宿主维护使用独立的事件写凭据，并绑定专用测试日历。

已验证的维护范围

已在专用测试日历完成两轮工程事件的标题、地点修改与恢复，以及有归属的新增事件清理和重复 reset。现有 primary 日历不作为维护目标。

02 / Data flow

数据会经过模型服务，并写入轨迹

Calendar 工具返回的事件内容可能进入后续模型请求。项目保存完整请求、工具返回和模型响应；它们可能含有日历原始内容，而不只是匿名统计。

  1. 01Google Calendar授权范围内的日历与事件
  2. 02MCP 工具查询或显式授权的维护操作
  3. 03执行程序 / LiteLLM组织模型与工具交互
  4. 04配置的模型服务处理任务上下文并返回结果
  5. 05操作者的运行存储轨迹、结果及维护快照

03 / Your controls

授权与数据管理

Google 授权由账号持有人完成。授权可以在 Google 账号连接管理中撤销。撤销授权不会自动删除已保存的轨迹或快照，需由操作者清理。

本说明网站没有登录、上传表单、统计脚本或 Calendar API 调用。
